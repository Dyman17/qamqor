# Прошивка смарт-ошейника Qamqor v2.1 PRO (ESP32-WROVER)

Профессиональная прошивка для микроконтроллера **ESP32-WROVER** с поддержкой внешней PSRAM, цифровым аудио ЦАП/усилителем **MAX98357 (I2S)**, вибромотором тактильного предупреждения, безопасным импульсным генератором **400 кВ** и **GPS** на защищенных пинах.

---

## 🔌 Схема подключения (Hardware Pinout)

| Модуль | Пин модуля | Пин ESP32-WROVER | Назначение / Примечание |
| :--- | :--- | :--- | :--- |
| **GPS NEO-6M / ATGM336H** | `TX` | **GPIO 32 (RX2)** | Прием NMEA координат |
| | `RX` | **GPIO 33 (TX2)** | Передача команд (опционально) |
| | `VCC` | `3V3` / `VIN` | Питание модуля |
| | `GND` | `GND` | Общая земля |
| **I2S Усилитель MAX98357** | `BCLK` | **GPIO 26** | Bit Clock |
| | `LRC / WS` | **GPIO 25** | Word Select (Left/Right Clock) |
| | `DIN / DOUT` | **GPIO 22** | Serial Data |
| | `GAIN` | `GND` / `100k` | Коэффициент усиления (+9dB .. +12dB) |
| | `VIN` | `VIN (5V)` | Питание 3W Class D усилителя |
| | `GND` | `GND` | Общая земля |
| **Вибромотор** | Затвор / База | **GPIO 27** | Тактильное предупреждение животного (MOSFET/NPN) |
| **Генератор импульсов 400кВ** | Затвор MOSFET | **GPIO 19** | Электропастух с оптронной развязкой (дозировано 150 мс) |
| **Статус LED** | Анод | **GPIO 2** | Встроенный индикатор режимов |

> [!CAUTION]
> **Внимание для ESP32-WROVER:**
> Пины **GPIO 16** и **GPIO 17** категорически запрещено использовать для периферии, так как они подключены к внутренней высокоскоростной шине PSRAM (Quad/Octal SPI RAM). GPS модуль подключен строго к **GPIO 32** и **GPIO 33**.

## 🛡️ Безопасность и защита животного (400kV Safety Interlocks)

1. **Дозирование импульса:** Длительность каждого электро-импульса жестко ограничена **150 миллисекундами** (`SHOCK_DURATION_MS = 150`).
2. **Обязательный кулдаун:** Между срабатываниями выдерживается обязательная пауза не менее **6000 миллисекунд (6 сек)** (`SHOCK_COOLDOWN_MS = 6000`).
3. **Аппаратная блокировка (Lockout):** Разрешено не более **3 последовательных импульсов**. Если скот не отступил назад после 3 воздействий:
   - Шокер **полностью блокируется** (`isShockLockedOut = true`, GPIO 19 переводится в LOW).
   - Включается **аварийная звуковая сигнализация** для привлечения чабана/пастуха.
   - Животное защищено от перегрузок и травм.
4. **Сброс блокировки:** Автоматически происходит, когда скот отступает назад в безопасную зону (`GREEN` или `YELLOW`).

## 🗺️ Мульти-зонный алгоритм (Virtual Fence Zones)

| Зона | Описание | Звук (I2S MAX98357) | Вибрация (GPIO 27) | Шок 400кВ (GPIO 19) |
| :--- | :--- | :--- | :--- | :--- |
| **GREEN** | Внутри пастбища | **Тишина** (0 samples) | Выключена | Выключен |
| **YELLOW** | Приближение к границе | Прерывистые импульсы низкой частоты (~800–1400 Гц) | Мягкие импульсы (200мс/800мс) | Выключен |
| **ORANGE** | Опасная буферная зона | Непрерывный звук повышенной частоты (~1600–2400 Гц) | Учащенная пульсация (350мс/350мс) | Выключен |
| **RED** | Выход за границу пастбища | Непрерывная тревожная агро-сирена | Непрерывная тревожная вибрация | Дозированный импульс 150 мс (макс 3 раза) |
| **ESCAPE** | Побег / скот далеко ушел | **Полная тишина** | Выключена | **Отключен** (защита от паники) |

## 📦 Необходимые библиотеки

1. **ArduinoJson** (версия 6.x или 7.x)
2. **TinyGPSPlus**
3. Встроенный ESP32 SDK (`WiFi.h`, `HTTPClient.h`, `driver/i2s.h`)

## 🏢 Тестирование в помещении (Indoor Pinging)

При включении ошейника в лаборатории или помещении (когда нет прямой видимости спутников GPS), встроенный алгоритм переходит в режим контрольного пинга с безопасными координатами. Это позволяет полноценно тестировать реакцию зон, I2S звук, вибромотор и кулдаун шокера через веб-панель управления и REST API:
`POST https://qamqor-api.onrender.com/api/v1/device/telemetry`
