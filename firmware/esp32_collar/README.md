# Прошивка смарт-ошейника ESP32 (Qamqor Smart Collar)

Прошивка для микроконтроллера **ESP32** с модулем **GPS (NEO-6M / NEO-8M)** и **пьезозуммером (Buzzer)**.

---

## 🔌 Схема подключения (Wiring Diagram)

| Компонент | Пин компонента | Пин ESP32 | Примечание |
| :--- | :--- | :--- | :--- |
| **GPS NEO-6M** | `VCC` | `3V3` или `VIN (5V)` | Большинство модулей имеют стабилизатор на 3.3V |
| | `GND` | `GND` | Общая земля |
| | `TX` | `GPIO 16 (RX2)` | Передача данных от GPS в ESP32 |
| | `RX` | `GPIO 17 (TX2)` | Прием команд (опционально) |
| **Зуммер (Buzzer)** | `VCC / I/O / +` | `GPIO 18` | Управляющий сигнал |
| | `GND / -` | `GND` | Общая земля |

> **Тип зуммера:**  
> - **Активный зуммер (со встроенным генератором):** пищит при подаче высокого уровня (`HIGH`). В коде установите `BUZZER_IS_PASSIVE = false`.  
> - **Пассивный динамик:** генерирует звук через частоту `tone()`. В коде установите `BUZZER_IS_PASSIVE = true`.

## ⚙️ Настройка перед прошивкой

В файле [`esp32_collar.ino`](./esp32_collar.ino):
1. Укажите имя и пароль вашей Wi-Fi сети (или точки доступа с телефона):
   ```cpp
   const char* WIFI_SSID     = "ВАШ_WIFI";
   const char* WIFI_PASSWORD = "ВАШ_ПАРОЛЬ";
   ```
2. Адрес сервера уже настроен на ваш рабочий продакшн:
   ```cpp
   const char* SERVER_URL = "https://qamqor-api.onrender.com/api/v1/device/telemetry";
   ```

## 🎯 Логика работы

1. Модуль считывает GPS-координаты скота.
2. Отправляет POST-запрос на сервер.
3. Сервер вычисляет пересечение полигона геозоны пастбища.
4. **Если скот вышел за пределы:** сервер присылает `inFence: false, vibrate: true` $\rightarrow$ зуммер начинает **непрерывно прерывисто пищать** (500 мс гудок / 200 мс пауза), поднимая тревогу.
5. **Как только скот вернулся в границы загона:** сервер присылает `inFence: true` $\rightarrow$ зуммер **мгновенно выключается**.
