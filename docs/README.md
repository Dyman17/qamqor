# Qamqor — информация о проекте

Единственная папка для всей информации о проекте: ТЗ, идея, архитектура, дизайн-брифы, планы, QA-отчёты.

## Идея

Система виртуального выпаса скота по мотивам идеи https://www.halterhq.com/:
умный ошейник на животном + сервер + приложение для фермера + сайт.
Детали (функции, железо, рынок) ещё не зафиксированы — заполняются со слов владельца
и из проверенных источников, ничего не выдумываем.

## Порядок работ

1. Дизайн фронта в Figma (приложение + сайт) → утверждение владельцем.
2. Приложение для телефонов и планшетов (`app/`).
3. Сервер (`server/`).
4. Прошивка ESP для ошейника (`esp/`).
5. Сайт (`site/`).

## Структура репозитория

| Папка | Что внутри |
|---|---|
| `docs/` | вся информация о проекте (эта папка) |
| `app/` | мобильное приложение (телефоны и планшеты) |
| `server/` | сервер системы |
| `esp/` | прошивка ESP для ошейника |
| `site/` | отдельный сайт |

## Разделы docs (создаются по мере работы, см. CLAUDE.md §7)

- `docs/frontend/` — дизайн-брифы, аудит, стандарт качества; `docs/frontend/qa/` — QA-отчёты
- `docs/architecture/` — архитектура и решения (ADR)
- `docs/plans/` — планы реализации
- `docs/ai/` — состав агентов и workflow
