# Qamqor: текстовое описание интерфейса приложения (телефон и планшет)

Источники: [app-design-brief.md](app-design-brief.md) (утверждён, палитра B), [../requirements.md](../requirements.md). Этот файл описывает **содержание и структуру**: какие экраны есть, что где показано, какие данные, кнопки и тексты. Цвета, размеры, шрифты и отступы здесь не повторяются, они в брифе по именам токенов. По этому файлу интерфейс можно понять или собрать заново без Figma.

## 0. Как читать

### 0.1 Условные обозначения

| Метка | Значение |
|---|---|
| **[В]** | действие или экран доступны только владельцу |
| **[Р]** | доступно и владельцу, и работнику |
| **[Р\*]** | работнику только при включённом переключателе «Работник может менять границы» (бриф п. 6.9; сводка прав в п. 3.6 этого файла); без права **скрыто**, не disabled |
| **[needs-A#]** | требует подтверждения архитектора (бриф §12.1). Рядом указан запасной вариант, он рисуется и строится по умолчанию |
| **фаза 2** | не входит в первую версию (здоровье: охота, жвачка, отёл, активность); зарезервированных слотов в интерфейсе нет |
| «—» | значение неизвестно или не проверено на железе; показывается тире, число не подставляется |
| (kk?) | казахская строка черновая, нужна проверка носителем |
| † | текст предложен в этом документе, в брифе его нет; проверить при утверждении |
| `{…}` | подставляемое значение |

Все примеры данных намеренно фейковые: «Корова #0142», «Загон Северный», «Ошейник DEMO-07», числа «138 из 142» и т.п.

### 0.2 Роли

- **Владелец**: создаёт ферму, видит и меняет всё.
- **Работник**: приглашается владельцем по email. Всегда может: смотреть карту, стадо, профили, оповещения; менять данные животного («Изменить»); добавлять, привязывать, отвязывать и переназначать ошейники; менять язык, уведомления, подсказки, выходить. Рисовать/редактировать загоны и перегонять стадо может только при включённом владельцем переключателе «Работник может менять границы» (по умолчанию выключен). **Никогда** не может: удалять загоны (по умолчанию, ждёт подтверждения владельца, вопрос 20), менять лимиты сигналов и настройки фермы, управлять пользователями, создавать/добавлять фермы.
- Работник может состоять в нескольких фермах.

### 0.3 Языки

Казахский (kk), русский (ru), английский (en). Выбор при первом запуске и в настройках, применяется сразу. Все тексты ниже на русском. Казахские и английские строки даны для ключевых подписей в п. 3.7; остальные kk-строки нужно подготовить и проверить носителем. Слово «ошейник» по-казахски не определено (вопрос 10).

### 0.4 Общие правила данных и текста

- Время последней точки/связи: относительное («5 мин назад»), в подсказке абсолютное (`дд.мм.гггг чч:мм`, 24-часовое).
- Единицы: га, м, км.
- Энергия импульса, радиус, точность GPS, срок работы, время применения границы, пороги: «—» до проверки на железе.
- Заряд, версия прошивки, расстояние до границы, стрелка направления: показываются только если данные приходят (A9, вопрос 7); иначе элемента нет.
- Не обещаем эффект («корова не выйдет») и доставку («ошейники получат») без подтверждения.
- Состояния каждого экрана: загрузка, пусто, ошибка, нет связи (у телефона). «Ошейник без связи» — другая ситуация: это статус конкретного ошейника (бейдж), не баннер.

## 1. Карта переходов

### 1.1 Телефон

```
Запуск
├─ [нет сессии] S1 Вход / выбор языка
│    ├─ «Создать ферму» → S1a Создание фермы → S1b Мастер (2 шага, только владелец) → S2 Карта
│    ├─ «Забыли пароль?» → S1c Сброс пароля (3 шага) → S1 Вход
│    └─ «Войти» → S2 Карта
├─ [ссылка-приглашение] S1d Принятие приглашения → S2 Карта фермы
└─ [есть сессия] S2 Карта

Нижняя навигация (4 вкладки):
├─ Карта (S2)
│    ├─ кнопка фермы (если ферм > 1) → Лист «Переключатель ферм»
│    ├─ бейдж связи → S5 Стадо с фильтром «Нет связи»; пункты сводки в листе → S5 с фильтром
│    ├─ ⚙ → S9 Настройки
│    ├─ FAB «Моё положение» → [нет доступа] Лист «Нет доступа к геопозиции»
│    ├─ тап по маркеру → мини-карточка → S6 Профиль / «Выбрать для перегона» [Р*] → S4
│    ├─ тап по загону (на карте или в списке загонов) → S2a Лист «Загон» → «Редактировать» [Р*] → S3 / «Удалить» [В] → диалог
│    ├─ тап по оповещению в листе → S7 Оповещения
│    ├─ «Нарисовать забор» [Р*] → S3 Рисование
│    └─ «Перегнать стадо» [Р*] → S4 Перегон
├─ Стадо (S5)
│    ├─ строка → S6 Профиль → «Найти на карте» → S2; «Перегнать» [Р*] → S4;
│    │          «Привязать» (если ошейника нет) → S8a Мастер привязки; «Открыть ошейник» → S8 Лист «Ошейник»; «Изменить» → Лист «Изменить животное»
│    └─ режим выбора (долгое нажатие / «Выбрать») → «Перегнать» [Р*] → S4
├─ Оповещения (S7) → «Показать на карте» → S2; «Открыть профиль» → S6
└─ Ошейники (S8) → строка → Лист «Ошейник» → «Привязать»/«Сменить животное» → S8a; «Добавить» → S8a

Настройки (S9) — только через ⚙ на карте, не вкладка.
```

### 1.2 Планшет

Те же экраны. Вместо нижней навигации **левый рейл** (4 пункта + вверху переключатель ферм и язык, внизу «Настройки»). Вместо нижнего листа **боковая панель справа** (то же содержимое). «Стадо» и «Профиль» совмещены: список слева в панели, справа карточка выбранного животного. Режим рисования (S3) и перегона (S4) работают внутри боковой панели.

## 2. Экраны и сущности

Формат записи: назначение, кто, вход/выход, блоки сверху вниз, планшет, состояния, тексты. Идентификаторы S… — для ссылок.

### S1. Вход / первый запуск / выбор языка (экран 1 из requirements)

- **Назначение:** выбрать язык и войти (или создать ферму).
- **Кто:** все (без сессии).
- **Вход:** первый запуск, выход из аккаунта, истёкшая сессия †. **Выход:** S2 (вход), S1a (создать ферму), S1c (забыли пароль).

**Блоки:**

| № | Блок | Что показано | Управление |
|---|---|---|---|
| 1 | Название | слово «Qamqor» (временный логотип) | нет |
| 2 | Выбор языка (первым) | три ряда-радио: «Қазақша», «Русский», «English», каждое на родном языке; по умолчанию язык системы, если kk/ru/en, иначе ru | выбор применяется сразу, тексты экрана меняются |
| 3 | Форма входа | поле «Email» (формат email), поле «Пароль» (скрыт, кнопка «показать/скрыть») | ввод |
| 4 | Действия | «Войти» (основная); «Создать ферму» (вторичная, ссылка) | «Войти» отправляет email+пароль |
| 5 | Ссылка | «Забыли пароль?» | → S1c |

**Планшет:** форма в карточке по центру (480 px), фон узор «ковыль».

**Состояния:**

| Состояние | Что видит пользователь |
|---|---|
| Загрузка | кнопка «Войти» заменена индикатором, поля и кнопка недоступны |
| Ошибка входа | под полем: «Неверный email или пароль»; фокус возвращается на поле |
| Ошибка сети/сервера † | баннер «Не удаётся связаться с сервером» + «Повторить» |
| Нет связи (телефон) | баннер «Нет подключения к сети…»; «Войти» недоступна, рядом причина |
| Пусто | не применимо |

### S1a. Создание фермы (регистрация владельца) †

- **Назначение:** создать аккаунт владельца и ферму. **Кто:** новый пользователь. **Вход:** S1 «Создать ферму». **Выход:** S1b.
- **Поля:** «Название фермы» (текст, обязательно), «Email» (обязательно), «Пароль» и «Повторите пароль» (обязательно). Создатель автоматически владелец. (Состав полей выведен из решения «email + пароль + название фермы»; отдельный макет не описан в брифе.)
- **Кнопки:** «Создать» (основная), «Назад».
- **Ошибки:** «Не удалось создать аккаунт с этим email. Если аккаунт у вас уже есть — войдите или восстановите пароль.» † (нейтральная формулировка, не раскрывает, зарегистрирован ли адрес); «Пароли не совпадают» †; «Заполните поле» †.
- **Состояния:** загрузка (кнопка → индикатор), нет связи (кнопка недоступна, причина текстом).
- **Планшет:** как на телефоне, форма в карточке по центру (480 px).

### S1b. Мастер первой настройки (только владелец, только после создания фермы)

- **Назначение:** подвести к первому результату. Показывается один раз; пропустить можно. Название фермы уже введено в S1a, поэтому в мастере его нет.
- **Индикатор:** «Шаг n из 2» (2 сегмента).
- **Шаги:** 1 «Добавить ошейник» (переход в S8a, после привязки возврат в мастер); 2 «Нарисовать первый загон» (переход в S3, после применения мастер закрывается).
- **Управление:** «Далее», «Пропустить», «Назад».
- Работник мастер не видит: после принятия приглашения сразу карта.
- **Планшет:** как на телефоне, содержимое в карточке по центру †.
- **Состояния:** определяются вложенными экранами S8a и S3; сам мастер данных не загружает.

### S1c. Сброс пароля по email

- **Вход:** S1 «Забыли пароль?». **Выход:** S1 после успеха.
- **Шаг 1:** поле «Email», кнопка «Отправить ссылку».
- **Шаг 2:** текст «Проверьте почту. Если адрес зарегистрирован, мы отправили ссылку для смены пароля» (одинаков для любого адреса); кнопка «Отправить снова» недоступна на время интервала (значение не задано).
- **Шаг 3** (открывается по ссылке из письма): «Новый пароль», «Повторите пароль», показ пароля, «Сохранить». Успех → экран входа с сообщением †.
- **Ошибки:** ссылка недействительна/просрочена + «Запросить новую»; пароли не совпадают †.
- **Состояния:** загрузка (кнопка → индикатор), нет связи (кнопки недоступны).
- **Планшет:** как на телефоне, форма в карточке по центру (480 px).

### S1d. Принятие приглашения

- **Назначение:** работник принимает приглашение владельца. **Вход:** ссылка из email. **Выход:** S2 фермы.
- **Блоки:** выбор языка (как в S1); заголовок «Вас пригласили в ферму «{Название фермы}» как работник»; «Пригласил: {email владельца}».
  - Если email уже есть в системе: кнопки «Принять» (основная) / «Отклонить»; при необходимости сначала вход. Принятие **добавляет ферму в существующий аккаунт** и открывает её.
  - Если аккаунта нет: поля «Пароль», «Повторите пароль» (email подставлен, не редактируется), кнопка «Принять и создать аккаунт».
- **Ошибки:** «Приглашение недействительно или просрочено» + «Попросите владельца отправить новое»; email не совпадает с аккаунтом.
- **«Отклонить»:** приглашение закрывается, показывается сообщение «Приглашение отклонено» † + «Закрыть». Без сессии «Закрыть» ведёт в S1, с сессией — на карту текущей фермы.
- **Нет связи:** кнопки недоступны, рядом причина текстом †. Загрузка: кнопка → индикатор †.
- **Планшет:** как на телефоне, содержимое в карточке по центру (480 px).

### S2. Карта (главный экран, экран 2)

- **Назначение:** увидеть, где животные и все ли в зоне; перейти к действию.
- **Кто:** [Р]. **Вход:** после входа, вкладка «Карта». **Выход:** см. карту переходов.

**Блоки сверху вниз (телефон):**

| № | Блок | Что показано | Управление |
|---|---|---|---|
| 1 | Верхняя строка | кнопка фермы: название фермы (обрезка многоточием), «▾» если ферм больше одной; бейдж связи короткой формы «138/142» (на связи / всего; фейковые числа); ⚙ | ферма → Лист «Переключатель ферм»; бейдж → S5 с фильтром «Нет связи»; ⚙ → S9 |
| 2 | Карта | спутниковая подложка (переключается на «схему»); загоны (линии, подписи с названием); маркеры животных (малая точка, статус только у отклонения, бриф п. 7.6; при большом приближении номер: последние 4 цифры); кластеры (квадрат с числом) при более чем 30 маркерах; активный загон подсвечен; строка атрибуции источника тайлов в углу | тап по маркеру/кластеру/загону; жесты карты |
| 3 | Правая колонка кнопок | «Слои/схема»; «Моё положение»; «Ко всему стаду» | переключает слой; центрирует на пользователе; вписывает всех животных |
| 4 | Нижний лист (peek) | сводка: «Вне зоны: N · Без границы: N · Нет связи: N»; каждый пункт кнопка-фильтр → S5 с этим фильтром. Если всё в норме: «Всё в порядке, обновлено {время}» | пункты сводки |
| 5 | Нижний лист (half) | кнопки «Нарисовать забор» [Р\*] и «Перегнать стадо» [Р\*] друг под другом; список загонов (строка: название, число животных, статус «Применён» / «Черновик» †); до 3 ближайших оповещений | кнопки; тап по загону → S2a; тап по оповещению → S7 |
| 6 | Мини-карточка животного (после тапа по маркеру, лист peek→half) | «Корова #0142 · {бирка} · {статус} · {время последней точки}» | «Профиль» → S6; «Выбрать для перегона» [Р\*] → S4 с этим животным |
| 7 | Лист «Загон» | см. S2a | |

**Планшет:** верхней строки на всю ширину нет: плавающая плашка слева сверху с бейджем связи **в длинной форме** «На связи: 138 из 142», ферма и настройки в рейле. Блоки 4–7 в боковой панели справа (360 на 768, 420 на 1366). Те же три кнопки справа на карте.

**Состояния:**

| Состояние | Текст | Что доступно |
|---|---|---|
| Загрузка | карта: фон и «Загружаем карту»; лист: скелетон; больше 8 с: «Долго? Проверьте связь» + «Повторить» | всё действующее выключено |
| Пусто: нет животных | лист: «Здесь пока нет животных. Привяжите ошейник к животному» + «Добавить ошейник» (→ S8) | карта по ферме/местоположению |
| Пусто: нет загонов | «Нарисуйте первый загон» + кнопка (→ S3) [Р\*]; у работника без права только фраза | |
| Ошибка | баннер «Не удаётся связаться с сервером» + «Повторить»; карта по кэшу | просмотр |
| Нет связи (телефон) | баннер «Нет подключения к сети. Показаны данные на {время}»; маркеры из кэша, отметка «обновлено {время}» | рисование, перегон, сохранение недоступны |
| Лист развёрнут (full) | лист занимает экран до верхней строки: полный список загонов и оповещений, прокрутка; свернуть — шеврон или системное «Назад» | карта скрыта под листом |
| GPS устарел у животного | маркер в стиле «нет связи» (круг с диагональю), в листе «Нет связи {время}» | |
| Большинство ошейников без связи (Wi-Fi прототип) | одноразовая плашка: «Ошейники вне зоны Wi-Fi фермы не передают данные. Показано последнее известное положение» + «Понятно» | не повторяется, пока не нажато «Показать подсказки снова» |

### S2a. Лист «Загон»

- **Назначение:** показать загон и дать действия над ним.
- **Кто:** просмотр [Р]; «Редактировать» [Р\*]; «Удалить» [В].
- **Вход:** тап по загону на карте или по строке в списке загонов (S2, блок 5). **Выход:** S3 («Редактировать»), диалог удаления (см. S3), закрыть (ручка, шеврон, системное «Назад»).

| № | Блок | Что показано | Управление |
|---|---|---|---|
| 1 | Заголовок | название загона («Загон Северный») | |
| 2 | Число животных | «Животных: N» (бриф п. 6.2: число животных в строке загона) | |
| 3 | «Кто пасётся» † | название группы животных или «не назначено» | |
| 4 | «Площадь» † | «N га» (в брифе площадь показана только на плашке при рисовании) | |
| 5 | «Статус» † | «Применён» / «Черновик» (черновик появляется при ошибке отправки или без связи, S3) | |
| 6 | Действия | «Редактировать» [Р\*] → S3; «Удалить» [В] → диалог (см. S3) | кнопки, недоступные роли, **скрыты** |

- **Планшет:** то же в боковой панели.
- **Состояния:** загрузка — скелетон, кнопки недоступны; ошибка † — «Не удалось загрузить загон» + «Повторить»; нет связи — данные из кэша, «Редактировать» и «Удалить» недоступны с текстом «Нет подключения к сети» †; пусто не применимо.

### Лист «Переключатель ферм»

- **Когда:** тап по кнопке фермы (на планшете в рейле); показывается, только если ферм больше одной.

- **Когда:** «Моё положение» без разрешения. **Текст:** «Нет доступа к геопозиции. Карта и стадо работают без неё». **Кнопки:** «Открыть настройки устройства», «Закрыть». Карта центрируется на ферме.

### S3. Рисование и редактирование забора / загона (экран 3)

- **Назначение:** нарисовать контур загона, назвать, указать, кто в нём пасётся, сохранить и применить.
- **Кто:** [Р\*]. **Вход:** S2 «Нарисовать забор» или «Редактировать» в Листе «Загон». **Выход:** S2.
- **Модель (по умолчанию, **[needs-A1]**, блокирующий):** один объект «Загон» = многоугольник + название + группа животных («Кто пасётся»). У животного не более одной активной границы. Типов «внешний/внутренний» и буфера в v1 нет. Животное без загона в состоянии «Без границы».

| 2 | Карта | спутниковая подложка; контур: поставленные вершины (квадраты), штриховая линия закрытия от последней к первой; прицел в центре экрана | тап ставит вершину; перетаскивание вершины; тап по середине ребра добавляет вершину |

| Поле | Значение | Источник |
|---|---|---|
| «Название» | текст, обязательно | ввод |
| «Кто пасётся» | выбор группы животных или «Назначить позже»; рядом число животных группы | ввод/сервер |
| «Тип», «Буфер предупреждения» | **скрыты в v1** (вопрос 3, A1, A2) | |

**Диалог применения:** «Применить границу для «{название}»? Это изменит границу для {N} животных». Кнопки «Применить» / «Назад к рисованию». Сроков доставки не обещаем.
**После применения:** тост «Загон сохранён», контур на 1.2 с подсвечивается. Кнопка «Отменить» в тосте на 8 с — только **[needs-A3]** (история версий); запасной вариант: тоста-отмены нет, вернуть можно повторным редактированием. Откат шагов рисования (↶ ↷) работает до «Готово» всегда.

**Состояния:**

| Состояние | Текст/поведение |
|---|---|
| Загрузка | после «Применить» кнопка → индикатор, контролы недоступны |
| Ошибка отправки | диалог «Не удалось применить. Граница сохранена как черновик» + «Повторить»; черновик остаётся |
| Нет связи | рисовать можно; «Сохранить и применить» заменена на «Сохранить черновик»; баннер объясняет, что применение возможно при появлении связи |
| Пусто | не применимо (режим всегда с пустого холста) |
