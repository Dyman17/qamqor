# docs/frontend: индекс

Читать по порядку:

1. [../requirements.md](../requirements.md): решения владельца и список экранов (обязательно).
2. [../research/halter.md](../research/halter.md): исследование паттернов (только паттерны, бренд не копируем).
3. [app-design-brief.md](app-design-brief.md): дизайн-бриф приложения (телефон и планшет). **Визуальная часть v3 (разделы 1–4, 7.6, движение): направление A3 «Горизонт современный»**; UX, экраны, потоки и права без изменений. Палитра B, Noto и Lucide устарели.
3a. [directions/](directions/index.html): три направления и уточнения A2, A3 (живые HTML-макеты экрана «Карта», телефон и планшет), [directions/README.md](directions/README.md) (токены, контраст, лицензии, самокритика); утверждено A3, образец `directions/a3-horizon-modern.html`.
3b. [../research/premium-ui-references.md](../research/premium-ui-references.md): референсы премиального UI, шрифты с проверенным казахским, иконки, легальные карты, 10 принципов.

4. [app-ui-spec.md](app-ui-spec.md): текстовое описание всего интерфейса приложения (экраны, блоки, данные, тексты, права, словарь данных); читать после брифа.

5. [site-brief.md](site-brief.md): дизайн-бриф сайта `site/` (draft, 2026-11-09): лендинг с 3D-моделью ошейника (раскадровка прокрутки, токены тёмной ступени, стекло, производительность, reduced-motion) и веб-кабинет (вход, карта, стадо, оповещения, ошейники, поток «Подключить устройство» с одноразовым секретом, настройки, роли). Визуальный язык A3, без новых зависимостей сверх Vite, three.js, MapLibre.
