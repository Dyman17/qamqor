# Qamqor: материал для «премиального» UI (референсы, иконки, шрифты, карта, принципы)

Дата: 2026-11-07. Назначение: дизайнеру (ui-designer) для брифа v3 после отказа от первых макетов.

## Как читать пометки

- **[проверено]** — получено в этой сессии из первоисточника (файлы шрифтов и пакетов, официальные страницы).
- **[знание]** — описание из моих знаний о продукте, в этой сессии не перепроверялось по скриншотам. Дизайнеру нужно открыть приложение или листинг и сверить глазами.
- **[не проверено]** — лицензия или факт требует проверки перед использованием.
- Ничего из референсов не копируем: берём только принципы.

Ограничение: визуал Halter, App Store-скриншоты и Dribbble получить как изображения не удалось (поиск вернул только подписи к скриншотам). Раздел 1 поэтому опирается на [знание] и требует визуальной сверки.

**Рекомендация (топ-2):**
1. **Phosphor** — основной. Единственный из проверенных с коровой, фермой, хлевом, трактором. Шесть весов дают иерархию: light для навигации, fill для активного состояния, duotone для акцентных иконок и пустых состояний. Недостающие **fence** и **satellite** нарисовать самим в логике Phosphor либо взять с Tabler/Hugeicons, подогнав толщину.
2. **Tabler** — донор для fence, satellite, route. Толщина stroke настраивается (1.5 совпадает с Phosphor light). Не «дороже» Lucide по виду, но шире по охвату. Если нужен более изящный вид, Iconoir, но покрытие слабое.

Для самих маркеров животных иконка коровы не нужна: точка с кольцом (принцип 6).

Важно: Manrope, один из самых частых «премиальных» шрифтов, **не содержит** большинства казахских букв, браузер подставит запасной шрифт. Не использовать.

**Рекомендуемые пары:**
1. **Inter одна семья** (самый безопасный вариант): текст — opsz 14, крупные заголовки и числа — opsz 32 (Display), `font-variant-numeric: tabular-nums`, веса 400/500/600 вместо тяжёлого bold. Один файл, одна семья.
2. **Onest (интерфейс) + Geologica Light/Regular (крупные числа и заголовки экранов)**. Geologica даёт мягкий «outdoor»-характер, Onest — спокойное тело. Обе variable, OFL. Визуально проверить Ә, Ұ, Ң.
3. **Golos Text + Geologica** — запасной вариант, если Onest покажется слишком геометричным; менее выразителен.

`tnum` есть у Inter, Onest, Geologica, Golos Text: включать для батареи, сигнала, координат, времени, площади.

Предупреждение: наличие subset `cyrillic-ext` в METADATA.pb само по себе НЕ доказывает полноту казахских букв (у Manrope он есть, а букв нет). Нужна проверка cmap.

Источники: https://github.com/google/fonts/tree/main/ofl/inter , https://github.com/google/fonts/tree/main/ofl/onest , https://github.com/google/fonts/tree/main/ofl/geologica , https://github.com/google/fonts/tree/main/ofl/golostext , https://github.com/google/fonts/tree/main/ofl/manrope (и METADATA.pb каждого: подмножества, лицензия OFL, оси)

## 4. Карта для макетов

### 4.1 Что нельзя
**Google Maps/Earth, Mapbox, Esri World Imagery** без отдельной лицензии не использовать. Частично подтверждено: сотрудник Esri на форуме писал, что World Imagery не предназначен для экспорта тайлов (для этого есть отдельный слой с иными условиями) [вторичный источник, не лицензия]. Официальные условия Google и Mapbox в сессии не открывались [не проверено]; консервативно считаем запрещёнными для скриншотов в публичном репозитории.

### 4.2 Спутник: Copernicus Sentinel-2 (рекомендуется)
- Лицензия [проверено по Sentinel Data Legal Notice]: свободный, полный, открытый доступ; разрешены воспроизведение, распространение, изменение, комбинирование; обязательна ссылка на источник. Для изменённых данных: **«Contains modified Copernicus Sentinel data [год]»** (для макета «Contains modified Copernicus Sentinel data 2026»). Отказ от претензий к ЕС.
- Как получить чистый кадр: Copernicus Browser (browser.dataspace.copernicus.eu; нужен бесплатный аккаунт, создать должен владелец). Sentinel-2 L2A, область в степи, дата с облачностью около 0%, вкладка «Analytical», Download в JPG/PNG/GeoTIFF true colour. Разрешение 10 м/пиксель [по форумному обсуждению; мозаики грубее].
- Честное ограничение: при 10 м/пикселе участок 2 км — около 200 px, на телефоне (плотность 3×) картинка будет мягкой. Для макета использовать как «текстуру местности» (реки, проплешины, борозды), не рассчитывая на мелкие детали; добавить цветокоррекцию и лёгкое зерно.
- Для настоящего приложения нужен коммерческий снимок высокого разрешения (лицензия) или векторная база; решение владельца.

### 4.3 Landsat
USGS: данные в общественном достоянии без ограничений, но запрашивается цитирование [проверено]. Разрешение 30 м, хуже Sentinel-2; только как резерв.

### 4.4 Векторные стили
- **OpenFreeMap** [проверено]: бесплатно, без ключей, на публичном инстансе без лимита просмотров; стили Positron, Bright, Liberty, Dark, Fiord, 3D; лицензия MIT; данные OSM (ODbL); атрибуция обязательна (OpenMapTiles и OpenStreetMap; упоминание OpenFreeMap опционально); коммерческое использование разрешено. MapLibre добавляет атрибуцию сам; для статичного снимка добавить вручную.
- **Protomaps** [частично проверено]: система под BSD и ODbL; flavors: light, dark (с иконками), white, grayscale, black (для визуализации данных). Тайлы можно хостить самим одним файлом PMTiles. Отдельная лицензия на стили и тайлы не открывалась [не проверено].
- Для премиального вида: Positron / Dark / Fiord или grayscale / black как нейтральная подложка под наш слой (границы, животные).

### 4.5 Лучший путь для статического макета
1. Слой «Карта»: OpenFreeMap Positron (день) и Dark (ночь) через MapLibre, одноразовый снимок области степи Казахстана, палитра подкрашена под проект (приглушить воду и дороги).
2. Слой «Спутник»: кроп Sentinel-2 true colour с мягкой цветокоррекцией, внизу мелкая подпись «Contains modified Copernicus Sentinel data 2026».
3. Поверх — собственный слой в HTML/SVG (границы пастбищ, точки животных).
4. Сохранённые изображения положить в репозиторий с файлом ATTRIBUTION.
Новых зависимостей в проекте не появляется, если карту снять один раз и сохранить как WebP; запуск MapLibre для съёмки — разовый инструмент, на его использование нужно согласие владельца (правило 5 CLAUDE.md).

Источники: https://sentinel.esa.int/documents/247904/690755/Sentinel_Data_Legal_Notice , https://dataspace.copernicus.eu/node/10 , https://cop4schools.readthedocs.io/en/latest/part4/4_1.html , https://forum.dataspace.copernicus.eu/t/can-we-automate-analytical-kmz-jpg-download/3084 , https://www.usgs.gov/centers/eros/data-citation , https://openfreemap.org/ , https://docs.protomaps.com/basemaps/flavors , https://community.esri.com/t5/arcgis-image-server-questions/arcgis-online-basemap-imagery-licensing/m-p/257788

## 5. Десять принципов «премиального» мобильного UI

Привязка к референсу — [знание], кроме отмеченного.

1. **Карта — это экран, интерфейс — тонкий слой поверх** (Halter, Apple Maps, Tesla). Карта на всю высоту, под статус-баром и нижней навигацией.
2. **Плавающие контролы на полупрозрачном blur-материале** (Apple Maps; Apple HIG, Materials). Круглые кнопки 44–48 px, без обводки, мягкая тень; `backdrop-filter: blur(20px) saturate(1.4)`; при «Уменьшить прозрачность» — непрозрачная замена.
3. **Нижний лист с тремя положениями и «ручкой»** вместо отдельных экранов и модальных карточек (Apple Maps, onX). Радиус 20–28 px, без внешней рамки.
4. **Группированные списки без рамок** (Apple Settings, Find My): строки на общем фоне, разделитель — волосяная линия с отступом слева, а не рамка у каждой карточки.
5. **Один акцент** (Strava, Tesla). Акцентный цвет только для главного действия и выбранного состояния; статусы (норма / внимание / авария) — приглушённая тройка, используется точечно (Flighty: цвет только при отклонении).
6. **Минималистичные маркеры**: точка 10–12 px с тонким белым кольцом, цвет = состояние; галочек и иконок на каждом животном нет; иконка или подпись только у выбранного. Стадо кластеризуется при отдалении (Find My, тепловая карта Strava).
7. **Иерархия размером и весом, а не коробками** (Flighty, Garmin). 3–4 размера, веса 400/500/600, крупные числа 28–40 px с `tabular-nums`, подписи мелкие и приглушённые; жирный 700+ почти не используется.
8. **Приглушённая подложка, яркие данные** (Strava, Windy, onX). Карта обесцвечена, граница пастбища — линия 1.5–2 px + заливка 8–12% акцента; активная зона выделена, остальные слабее.
9. **Сдержанная глубина**: 1–2 уровня теней, мягких и широких (blur 24–40, непрозрачность 8–12%), без жёстких бордюров; граница только как волосяная линия 0.5–1 px там, где нужен контраст.
10. **Тихое, осмысленное движение и полноценная тёмная тема** (Apple Maps, Flighty, Tesla, Rivian): пружинные переходы листа 250–350 мс, плавный наезд камеры на животное, всё уважает `prefers-reduced-motion`; тёмная тема спроектирована отдельно, а не инверсией.

Добавка по кнопкам: заливные кнопки с радиусом из того же ряда, что листы; вторичные действия — текстовые; пилюли только для настоящих фильтров, не как украшение статусов.

## 6. Рекомендации дизайнеру

1. Сверить по скриншотам листингов Halter, Apple Maps, Flighty, onX (раздел 1 не подтверждён картинками).
2. Утвердить шрифты (вариант 1 или 2), проверить рендер Ә ә Ғ ғ Қ қ Ң ң Ө ө Ұ ұ Ү ү Һ һ І і, включая заглавные формы, во всех используемых весах.
3. Утвердить Phosphor и дорисовать fence и satellite.
4. Решить с владельцем, как снимать карту (MapLibre как разовый инструмент).
5. Заменить насыщенный «стандартный» зелёный приглушённой палитрой (оливково-шалфейной) с одним акцентом; конкретные значения — в брифе.
