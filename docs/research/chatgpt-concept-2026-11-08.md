# QAMQOR — сводка концепции из чата владельца с ChatGPT

Получено от владельца 2026-11-08. Это пересказ обсуждений, а не проверенные факты. Сверка с нашими решениями: [chatgpt-concept-diff.md](chatgpt-concept-diff.md). Решения владельца в [../requirements.md](../requirements.md) имеют приоритет.

Подписи картинок из исходника (monil.com, leader-w.com, smartshape.design) убраны.

## 1. Идея и цель

Qamqor — Smart Livestock Monitoring System: GPS-мониторинг и управление выпасом с помощью смарт-ошейника и программной платформы.

Проблемы: потеря и кража скота; сложно контролировать большие стада на обширных пастбищах; нельзя вручную постоянно следить за каждым животным; бесконтрольный скот угрожает людям и инфраструктуре; дорогие потери (верблюды, лошади).

| Параметр | Информация |
|---|---|
| Основной пользователь | Фермер / владелец хозяйства |
| Дополнительный пользователь | Пастух |
| Основной регион | Мангистауская область |
| Потенциальный рынок | Западный Казахстан |
| Размер хозяйства | Не решено |
| Объект мониторинга | КРС; также обсуждались верблюды и лошади |

Цель: дистанционный контроль животных, предотвращение выхода за границы пастбища, снижение риска потери скота.

Аудио: два независимо управляемых динамика; частота растёт по мере приближения к границе; разные стороны ошейника для направленного воздействия. Совместимость усилителя, двух динамиков и питания не проверена.

Корпус: чёрный, минималистичный, референс Halter с более плавным изгибом, без острых углов; сверху солнечная панель, внутри контакт датчика пульса и вибромодуль, по бокам динамики. Не решено: габариты, материал, класс влагозащиты, ремешок, обслуживание аккумулятора.

## 3. Сигналы животному

1. **Звук** при приближении к границе; ближе — выше частота; два динамика, животное уходит от стороны звука.
2. **Вибрация**, если звука мало; контактная площадка со стороны шеи.
3. **Электроимпульс** — обсуждался как крайняя ступень при выходе за границу. Модуль, параметры, длительность и безопасный предел не определены; самодельная схема не утверждена; нужны ветеринарное и нормативное подтверждение и независимые испытания.

| Ситуация | Реакция |
|---|---|
| Приближается к границе | Звук |
| Продолжает приближаться | Усиление звука |
| Звука недостаточно | Вибрация |
| Вышло за границу | Обсуждалась третья ступень |

Адаптация: первые 10 дней — знакомство с ошейником, приучение к звуку, связь сигнала с направлением, проверка реакции на вибрацию. Программа Halter не подтверждена. Не решено: расписание, интенсивность, длительность, критерии успеха.

## 4. Виртуальный загон

Фермер задаёт территорию → система хранит границы → GPS даёт координаты → сравнение с границами → предупреждения при приближении → при пересечении событие и уведомление фермеру.

Не решено: способ рисования загона, дистанция запуска сигнала, частота GPS, фильтрация ошибок GPS, поведение при возвращении животного, поведение при потере GPS.

## 5. Мобильное приложение

Структура не зафиксирована. Функции: координаты животных, карта, создание загона, контроль выхода, уведомление о выходе — требуются/обсуждались; состояние ошейника, пульс, история перемещений, несколько животных — не решено. Роли: фермер (владелец), пастух (дополнительный). Права доступа не обсуждались подробно.

## 6. Сервер и данные

Архитектура не разработана. Данные: ID ошейника, координаты, время, ID животного, границы, история, события выхода, пульс, уровень аккумулятора, состояние связи (большинство «не решено»). Не решено: платформа, БД, частота отправки, протокол, работа без интернета, локальное хранение и синхронизация.

## 7. Здоровье

Обсуждался только пульс: датчик на внутренней стороне ошейника. MAX30102 упоминался, пригодность для КРС не подтверждена. Не решено: модель, контакт с кожей, работа через шерсть, частота, алгоритм отклонений, другие показатели.

## 8. Бизнес

Продажа ошейников + подписка (SaaS); рынок — фермы Западного Казахстана; цены не зафиксированы. Конкурент и референс — Halter. Потенциальный партнёр — Q-AGRO (не подтверждено).

## 10. Следующие шаги (из исходника)

Железо: модели ESP32 и GPS, выбор GSM/LTE или LoRa, два динамика с MAX98357A, вибромодуль, аккумулятор и энергопотребление, солнечная панель, пульс у КРС, влагозащищённый корпус.
Управление: алгоритм частоты звука, логика левого/правого динамика, алгоритм вибрации, безопасная программа адаптации, ветеринарная оценка; импульсную ступень не внедрять без испытаний и нормативного подтверждения.
Пилот: прототип → GPS → динамики → вибрация → тестовая граница → связь с платформой → испытания с хозяйствами и ветеринарами → оценка точности, автономности, надёжности.
