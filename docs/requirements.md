# Qamqor: требования к первой версии

Источники: ответы владельца в чате (2026-11-06), исследование [research/halter.md](research/halter.md).

## 1. Решения владельца (подтверждено)

| Тема | Решение |
|---|---|
| Идея | Умные ошейники с виртуальным забором для скота, по мотивам Halter. Свой бренд, Halter не копируем. |
| Животные и пользователи | КРС, фермеры Казахстана |
| Языки | казахский, русский, английский (приложение и сайт) |
| Визуальный стиль | природный, спокойный: земля, трава, степь, много воздуха, карта в центре |
| Figma | новый файл в аккаунте владельца |
| Объём первого дизайна | **только приложение** (телефон и планшет); сайт позже |
| Связь ошейника (прототип) | обычный Wi-Fi: ESP подключается к локальному роутеру, пароль прописан в прошивке |
| Датчики | **пока не решено**: экраны здоровья (охота, жвачка, отёл) в первую версию не входят, только «фаза 2» |
| Порядок работ | Figma → утверждение → приложение → сервер → ESP → сайт |

## 2. Допущения (нужно подтвердить)

- Ошейник умеет: GPS-позицию и сигналы управления «звук → вибрация → импульс». Взято из прошлой версии проекта (тег `archive/v1-before-reset`: динамик MAX98357, вибромотор, импульс), для нового железа не подтверждено.
- Есть датчик заряда батареи (показываем заряд, если он реально есть; иначе скрываем).
- При Wi-Fi-прототипе ошейник работает только в зоне роутера: приложение должно честно показывать «онлайн / последний раз на связи».
- Приложение на мобильной платформе (React Native или Flutter) решит архитектор; на дизайн не влияет.

## 3. Экраны приложения, первая версия (рекомендация)

1. Вход / первый запуск, выбор языка (kk / ru / en).
2. **Карта** (главный экран): спутниковая подложка, животные, загоны и виртуальные заборы, статус связи.
3. Рисование и редактирование виртуального забора / загона.
4. Перегон стада: выбрать группу (в том числе «лассо» на карте) → указать новый загон → подтвердить.
5. Список стада: поиск, фильтры (вне зоны, нет связи, низкий заряд).
6. Профиль животного: номер, бирка, ошейник, позиция, история событий и сигналов.
7. Оповещения: вышло за забор, нет связи, низкий заряд, достигнут лимит сигналов.
8. Ошейники: привязка ошейника к животному, статус, заряд, последняя связь.
9. Настройки: ферма, язык, пользователи, лимиты сигналов (благополучие животных).

Состояния у каждого экрана: загрузка, пусто, ошибка, нет связи (офлайн).
Раскладка: телефон (карта + нижняя панель); планшет (карта + боковая панель).

## 4. Правила

- Цифры, отзывы и характеристики не выдумываем. Энергию импульса и подобные значения показываем только после проверки на реальном железе.
- Тексты, названия функций и визуальный стиль Halter не копируем.
- WCAG 2.2 AA, проверка казахских букв (ә ғ қ ң ө ұ ү һ і и заглавные) во всех шрифтах.
- Шрифты self-hosted, одна или две гарнитуры с полной кириллицей и казахскими буквами.

## 5. Открытые вопросы

- Состав датчиков ошейника (определяет фазу 2: здоровье).
- Связь в поле после прототипа (LoRa, сотовая связь или другое): решает владелец после сравнения от архитектора.
- Название и логотип: «Qamqor» как рабочее название?
